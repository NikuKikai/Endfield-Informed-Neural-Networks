# 终末地工厂稳态配平方案

## 计算图

以物品类型建立产物节点，以配方建立配方节点。物品分别标记“可外部输入”和“可生产”，两者可以同时成立。前者决定能否设置外部输入 `S_i ≥ 0`，后者决定是否出现在产物索引。配方的投入、产出数量和周期是固定数据；每个配方的运行速率 `x_r ≥ 0` 是可训练参数，单位为连续运行的设备当量，允许小数。所有物品速率使用每分钟。

对物品 `i`，由配方系数直接计算生产、消耗和净输出：

```text
P_i = Σ_r a⁺_ir x_r
C_i = Σ_r a⁻_ir x_r
N_i = P_i + S_i − C_i
```

`a⁺_ir`、`a⁻_ir` 分别为配方 `r` 在单位运行速率下生产、消耗物品 `i` 的速率，即每次数量乘 `60 / 配方周期秒数`。配方比例由此严格满足。图中“生产→消耗”的占比是解出的流量的派生量，不作为独立可训练权重。若需确定产物流向具体配方，可增加非负流量 `f_ir`，并约束各配方实际取用量与 `a⁻_ir x_r` 相等。

## 约束与目标

| 项目 | 约束或损失 |
| --- | --- |
| 非负速率 | 用 `softplus(θ)` 等参数化保证 `x_r ≥ 0`、可变的 `S_i ≥ 0`。 |
| 物料守恒 | 通常要求 `N_i ≥ 0`；恰好配平的中间物品设 `N_i = 0`。允许库存下降时显式给出下降额度。 |
| 目标产出 | 对选定物品设置 `N_i = d_i`；未设置目标的物品要求 `N_i = 0`。 |
| 外部供给 | 有限供给设 `0 ≤ S_i ≤ 上限`，无限供给只要求 `S_i ≥ 0`；不要求用完。上限为 0 时严格固定 `S_i = 0`，不影响配方生产。不可外部输入的物品始终 `S_i = 0`。 |
| 生产禁用 | 禁止生产某物品时，生产它的配方不可用；该物品仍可从外部输入并被其他配方消耗。 |
| 可选扩展 | 电力、物流吞吐等按速率计算并设置上限；价值按允许输出的 `N_i` 计算。 |

不考虑设备数量与整数化；配方速率可为连续值，并可换算为设备运行比例。对等式使用归一化平方误差，对外部输入上限使用单侧惩罚。总耗电可作为加权优化目标。目标互相矛盾时报告各约束残差，不把损失停止下降视为可行。关闭供给或禁用生产后，若物品没有外部供给且其已有生产配方全部失效，才从求解图中排除它及依赖它的配方。

## 求解与验证

由完整配方表生成固定系数矩阵，通过自动微分对配方速率反向传播。计算图允许配方链存在环，但物料流仍按上述稳态矩阵计算，避免递归展开。无界循环应由原料、电力、吞吐上限或明确的目标边界限制。

基础模型主要是线性约束与线性目标，可用线性规划结果校验梯度求解的可行性和最优性。最终方案再交给仿真器检查供电、缓存、端口优先级及物流造成的实际节拍差异。配方、物品和建筑数据拟从 IndustrialPlanner 的 `src/registry` 提取；具体字段与单位在实施时核对。
